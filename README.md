A very simple music player made in bash.
I made it cause I like music, and spotifiy takes too much resources.

REQUIREMENTS
- ffmpeg
- bash terminal
- Linux (Not supported on Windows or Mac officially)

INSTRUCTIONS
- run ``` curl -L https://github.com/morph0z/Bump/releases/download/Release/Bump.tar.gz > bump.tar.gz ```
- extract the folder open ```cd Bump/``` then run ```./bump.sh```
